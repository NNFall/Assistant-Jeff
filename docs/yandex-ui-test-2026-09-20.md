# Музыка и вкладки: тест с участием Codex

20 сентября 2026. Этот опыт предшествует [проекту автономного цикла](autonomous-computer-use.md).

Роли: Codex Computer Use наблюдал интерфейс через accessibility/скриншоты, Codex составлял текстовые кандидаты и исполнял выбранный шаг. Jev `1.13.0` выбирал ID через реальный API. Скриншоты в Jev не передавались. Поэтому этот опыт не доказывает самостоятельное управление установленным Assistant Jeff.

| Шаг | Выбор Jev | P / confidence | API | Подтверждение |
|---|---|---|---|---|
| Показать Музыку | show_music | 1 / 1 | 4811 мс | Окно на экране, Моя волна на паузе |

В Музыке **уже был выбран** режим «Незнакомое · Бодрое». Проверено возобновление этой волны; настройка чистого «Незнакомое» из исходного состояния не проверена. При переключении вкладок браузер сам показал видео в picture-in-picture. Это не отдельное действие Jev.

Проверка раскладки не выполнена: Computer Use остановился с сообщением о неподдерживаемой проверке политики URL для текущего Windows-браузера. Ограничение не обходилось. Установленное приложение не изменялось. Полную пользовательскую задержку здесь не измеряем: между API были ручные наблюдения и вызовы инструментов.

Исходный локальный журнал: `work/yandex-ui-test.json`. Скрипты `ui-experiment-session.mjs` и `choose-ui-once.mjs` сохраняют наблюдения/выбор отдельно от исполнения, не имеют OS-действий. `record()` сохраняет историю попыток, чтобы успешный fallback не стирал неудачный клик.
