# Assistant Jeff 0.2.0

Личный помощник для Windows: локально ждёт «Hey Jarvis», подаёт сигнал, распознаёт команду через облако, сохраняет заметки и напоминания, открывает разрешённые приложения и отвечает через Gemini. Новая оболочка — **Electron/JavaScript**, запускается как обычное Windows-приложение. Исходный Python-прототип сохранён как отдельный локальный запасной вариант.

## Попробовать

Откройте Assistant Jeff. Можно сразу написать команду в поле ввода:

- «Запиши заметку купить хлеб».
- «Поставь таймер на две минуты».
- «Напомни через полтора часа проверить чай».
- «Открой калькулятор» — также доступны Блокнот, браузер и Проводник.
- «Расскажи короткую шутку» — текстовый ответ Gemini.

Для голоса включите микрофон, дождитесь ожидания имени, произнесите **Hey Jarvis** и дождитесь сигнала. Затем говорите команду. Соединение с распознаванием открывается после активации: не произносите имя и команду слитно. Есть также ручная активация записи. В настройках доступны Alexa, Hey Mycroft и Hey Rhasspy.

Промежуточный текст отображается по мере получения от сервиса. Действие выполняется только после окончательной транскрипции. Текущий русский streaming-профиль **экспериментальный**: успешная проверка была на синтетической речи, не на вашем микрофоне.

Закрытие окна оставляет помощника в трее. Для полного завершения выберите **«Выход»** в трее. Автозапуск выключен по умолчанию; его явное включение в установленной версии запускает приложение в фоне и включает ожидание имени при входе в Windows.

## Что умеет и где границы

Jev выбирает намерение; код проверяет текст и параметры перед действием. Для запуска разрешены только четыре перечисленных приложения. Произвольные команды shell, пути, скрипты и клики по чужим окнам не выполняются. Gemini отвечает текстом и не имеет инструментов управления компьютером. Актуальная погода и веб-поиск пока не подключены.

Голосовые интервалы: секунды, минуты, часы, до 365 дней. Календарные формулировки вроде «завтра в десять» и составные интервалы пока не поддерживаются голосовым парсером; точную дату можно задать формой напоминания. Повтор команды создаёт новую запись.

Напоминания сохраняются между запусками. Во сне или при выключенном компьютере сигнал невозможен; просроченные появятся после возвращения приложения к работе. Windows может скрыть уведомление в режиме «Не беспокоить». Напоминание остаётся активным до явного завершения пользователем.

**Полноценное AEC не реализовано и не проверено.** Chromium запрашивает стандартное echoCancellation/noiseSuppression, но это не доказательство подавления звука YouTube или Bluetooth-динамиков. Приглушение других приложений относится к старому Python-прототипу и не перенесено в новую оболочку.

## Данные и облачные сервисы

Новая версия хранит SQLite, настройки и защищённые ключи в `%APPDATA%\Assistant Jeff`. При первом запуске из исходников существующая `data\assistant.sqlite` копируется через SQLite; оригинал остаётся на месте. Установленная сборка использует заранее подготовленную миграцию в эту папку и не содержит пользовательскую БД. Две версии после копирования не синхронизируются.

Заметки и напоминания в SQLite не зашифрованы. Сырые аудиозаписи приложение на диск не сохраняет. В ожидании имени звук обрабатывается локально. После сигнала аудио команды отправляется AssemblyAI; текст команды — TypeSafe, а разговорный запрос — через собственный закрытый шлюз в Gemini. База заметок целиком в модели не отправляется.

Отключение облачных моделей сохраняет точные текстовые локальные команды; голос в новой оболочке без AssemblyAI не работает. Для полностью локального голосового режима остался `launcher.pyw` исходного прототипа с faster-whisper. Не запускайте оба помощника одновременно.

TypeSafe/AssemblyAI оплачиваются по условиям аккаунта; Gemini и VPS также могут расходовать средства. Локальное ожидание имени не делает API-запросов. Стоимость всей команды и месячный бюджет не измерены; точные актуальные тарифы смотрите в [TypeSafe](https://console.typesafe.ai/), [AssemblyAI](https://www.assemblyai.com/pricing) и [Gemini](https://ai.google.dev/gemini-api/docs/pricing).

Ключи не хранятся в Git или установщике. Windows-копии защищены DPAPI текущего пользователя. Перенос зашифрованных файлов на другой компьютер/пользователя не является способом переноса доступа.

## Разработка и сборка

Рабочая папка: `D:\papka for all\work\Assistant Jeff`. Репозиторий: [NNFall/Assistant-Jeff](https://github.com/NNFall/Assistant-Jeff).

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
npm.cmd run build
```

`build` создаёт NSIS-установщик x64 в `release\`; `npm.cmd run pack` — распакованную сборку. `release`, `node_modules`, модели, данные и секреты не коммитятся. Установка из исходников требует подготовленных ONNX-файлов в `models\`; команды npm сами их не скачивают. Сборка 0.2.0 установлена и проверена на этом компьютере; установщик не подписан сертификатом издателя.

Разработчик может передать `TYPESAFE_API_KEY` и `ASSEMBLYAI_API_KEY` через окружение или подготовить DPAPI-хранилище. Gemini требует отдельного `gateway.json`, SSH host fingerprint, защищённых ключа и токена. В интерфейсе пока нет полного мастера настройки провайдеров. Подробности: [архитектура](docs/architecture.md).

## Проверенное состояние

48 тестов прошли, включая все четыре детектора имени и сравнение Jarvis с Python-эталоном. Проверены распакованный `.exe` и экземпляр после NSIS-установки: создание заметки/таймера, SQLite, загрузка ONNX и остановка голосового режима без включения настоящего микрофона. Ярлык **Assistant Jeff** установлен на рабочий стол; автозапуск оставлен выключенным. Сквозной синтетический сценарий имя → AssemblyAI → Jev → таймер также прошёл. `npm audit` не обнаружил известных уязвимостей на дату проверки.

Реальные небольшие запросы подтвердили Jev `1.13.0` на пяти русских фразах, включая отказ на отрицание; модель выбирается через alias `jev-latest`. Gemini `3.1-flash-lite` ответил через закрытый шлюз. AssemblyAI `whisper-rt` правильно распознал синтетическую трёхсекундную фразу примерно за 4,4 с от начала теста; Universal-3.5 Pro на той же фразе дал неверный текст. Это не проверка полного микрофонного сценария. [Методика и ограничения](docs/research.md).

Код openWakeWord — Apache-2.0, готовые wake-word веса — **CC BY-NC-SA 4.0**. Текущие веса подходят для личного некоммерческого эксперимента; перед коммерческим распространением нужен другой лицензионный выбор. [Источник](https://github.com/dscripka/openWakeWord#license).
