# Assistant Jeff 0.3

Голосовой помощник для реального Windows-компьютера. В одном Electron-приложении объединены ручные задачи, локальное ожидание **Hey Jarvis**, распознавание записанной команды через **Gemini 3.5**, управление доступными окнами и элементами через Jev, заметки, напоминания и локальный голос **Денис**.

`npm start` теперь открывает этот общий интерфейс. Старый интерфейс 0.2 сохранён отдельно: `npm run start:legacy`. Белое тестовое окно осталось только для регрессионных проверок.

## Использование

Введите команду и нажмите **«Выполнить»**:

- «Открой Steam» — показать существующее окно или запустить поддерживаемый ярлык меню «Пуск».
- «Сверни Google Chrome» — действие с настоящим окном.
- «Переключи раскладку на английскую» — только установленная English/Russian активного целевого окна.
- `Замени текст на «Привет»` — заменить всё значение заранее сфокусированного доступного поля, если операция поддерживается.
- «Запиши заметку купить хлеб».
- «Напомни через две минуты проверить чай».
- «Объясни, почему небо голубое» — текстовый ответ Gemini без инструментов управления.

Вопросы направляются в Gemini по префиксам **«Объясни»**, **«Расскажи»**, **«Вопрос:»**. Поддерживаемые локальные команды обрабатываются локально; задачи для компьютера идут в Windows-исполнитель. Выполнение произвольной задачи во всяком приложении не гарантируется.

Для голоса нажмите **«Ожидать Jarvis»** либо **«Сказать команду»** для одной записи. Имя определяется локально; кольцевой буфер хранит около 700 мс недавнего звука, чтобы уменьшить потерю начала фразы. После активации записывается команда. Через **2,5 секунды тишины** запись завершается, локально кодируется в MP3 и отправляется в Gemini 3.5 для транскрипции. Это распознавание готового фрагмента, а не потоковый вывод текста. AssemblyAI в новом пути не используется.

Сигнал активации, ответ Дениса и автоматическое выполнение после распознавания включаются отдельно. Если автоматическое выполнение выключено, текст остаётся в поле для проверки. Денис работает через нативный Piper локально, без Python. **«Стоп»** останавливает дальнейшую обработку; уже выполненные действия не отменяются. Закрытие основного окна оставляет приложение в трее; полный выход — через меню трея.

## Возможности и ограничения

Jev выбирает следующий шаг из предоставленных действий. Исполнитель проверяет цель и состояние до и после шага, а журнал сохраняет запросы, ответы модели, решения, native receipts, задержки и ошибки. Порог остаётся **probability ≥0,80 и confidence ≥0,80**. Отдельный вопрос о достижении цели использует тот же порог. Это проверки одной модели, а не гарантия понимания команды.

- Наблюдение основано на Win32 и UI Automation. Общего зрительного анализа экрана, рисования по координатам и управления недоступными UIA-элементами нет.
- Раскладка ограничена установленными English/Russian и активным целевым окном. Названное приложение может сначала потребовать активации; общий запрос для текущего поля не должен переключать пользователя в другое приложение.
- Текстовый инструмент принимает явную ограниченную строку из `замени текст на «…»` и заменяет **всё поле** через ValuePattern.SetValue. Это не дописывание и не эмуляция клавиатуры. Значение поля обратно не читается; receipt этой операции остаётся непроверенным, поэтому успешная отправка не объявляется подтверждённым вводом.
- Chromium запрашивает `echoCancellation` и `noiseSuppression`; качество AEC на реальном микрофоне в этой итерации не проверено. Приглушение звука других приложений ещё не подключено.
- Напоминания требуют работающего приложения. Голосовой парсер поддерживает интервалы в секундах, минутах и часах до 365 дней; календарные и составные формулировки не поддерживаются.

## Данные

SQLite и защищённые настройки провайдеров остаются в `%APPDATA%\Assistant Jeff`. Используется прежний `Store` и совместимая схема заметок/напоминаний. Существующая база не заменяется; если её ещё нет, исходная `data\assistant.sqlite` копируется через SQLite без изменения оригинала. Настройки нового голосового режима хранятся отдельно в `windows-voice-settings.json`.

Журналы команд доступны кнопкой **«Журнал»**. В запуске из исходников они лежат в `work\windows-desktop\runs`, в установленной сборке — в `%APPDATA%\Assistant Jeff\logs\windows`. Голосовые события — в `logs\voice` внутри папки данных. Аудиобайты в журналы не записываются. Названия окон, элементы и текст задач могут содержать личную информацию: во время задачи они передаются TypeSafe, записанная активированная команда — Gemini. Фоновой облачной трансляции микрофона в ожидании имени нет.

Ключи защищены Windows DPAPI текущего пользователя и не включаются в Git или установщик. SQLite с заметками и напоминаниями не зашифрована. Провайдеры требуют настроенного доступа; полного мастера настройки аккаунтов пока нет.

## Разработка и сборка

```powershell
npm.cmd ci
npm.cmd run windows:build
npm.cmd run prepare:runtime
npm.cmd start
npm.cmd test
npm.cmd run pack
npm.cmd run build
```

Перед запуском нужны wake-word ONNX-модели, модель Denis, нативный Windows helper, Piper и FFmpeg. `windows:build` собирает helper. `prepare:runtime` проверяет ресурсы и контрольные суммы, при необходимости устанавливает закреплённый Piper; отсутствующие wake-word/Denis модели не скачивает. `pack` и `build` сами выполняют эту подготовку. Подробности: [голосовой runtime 0.3](docs/voice-windows-v03.md).

`pack` создаёт распакованную Windows x64-сборку, `build` — NSIS-установщик в `release`. Секреты, базы и журналы в пакет не входят. Версия исходников и созданный установщик не означают, что пользователь уже установил обновление.

## Проверка

В текущей интеграции измерены отдельные реальные запросы: транскрипция MP3 Gemini — **1 966 мс**, разговорный `/chat` — **2 812 мс**. Это время отдельных API-вызовов, не задержка всей голосовой команды и не тест микрофона пользователя. Сквозное произнесение имени, реальный микрофон, AEC и поведение в шуме в этой итерации не проверены.

Устройство Windows-цикла и ограничения: [управление Windows](docs/windows-desktop.md). Голос, данные и упаковка: [версия 0.3](docs/voice-windows-v03.md). Старый изолированный стенд: [регрессионный fixture](docs/windows-lab.md). Исторические исследования остаются в `docs` и описывают свои версии, а не текущую готовность каждой функции.

openWakeWord имеет лицензию Apache-2.0, готовые wake-word веса — CC BY-NC-SA 4.0; они предназначены здесь для личного некоммерческого эксперимента. У Piper, его зависимостей и модели Denis отдельные лицензии; notices и model card включаются в runtime-ресурсы.
