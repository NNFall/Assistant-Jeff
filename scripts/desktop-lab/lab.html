Проверка состояния…

Напишите задачу для компьютера. Jeff запускает поддерживаемые программы из меню «Пуск», получает доступные окна и элементы Windows, выбирает действие и проверяет результат после каждого шага. Кнопка «Стоп» прерывает выполнение; запросы, решения и результаты сохраняются в журнале.

Пауза для завершения фразы — 2,5 с. Ожидание Jarvis работает локально. После включения подождите 2–3 секунды и произнесите «Hey Jarvis». В облако отправляется только записанная команда после активации словом Jarvis или кнопкой. Если автоматическое выполнение выключено, текст останется в поле для проверки.
